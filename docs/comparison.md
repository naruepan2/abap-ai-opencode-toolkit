# Copilot vs OpenCode — comparison scorecard

The two harnesses stay separate: no shared memory and no shared registries. The
goal is to compare how each one works, not to merge them.

## Rules

1. Same task, same input, same SAP target.
2. No shared memory between the two runs.
3. Record only what happened; do not score from impressions.
4. A result is evidence-backed only when the command or test is shown.
