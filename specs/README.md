# Specs mirror

Generated backup of the program contracts. **Do not edit these files.**

| | |
|---|---|
| Source of truth | `..\Projects\<PROJECT>\<PROGRAM>\spec.md` and `CHANGELOG.md` |
| Generated by | `python scripts\specs_sync.py --write` |
| Checked by | `python scripts\specs_sync.py` (exit 1 on drift) and `closeout.py` |
| Manifest | `manifest.json` - spec version, status, sha256 and size per file |
| **Not mirrored** | `spec\source\` (the customer FS): it is the customer's document, and this repository must not carry customer data |

Why a mirror: the spec is edited where the work happens (`Projects\`), which is not
a git repository; this repository is. The mirror gives the spec and its changelog a
history and an off-machine backup without turning the 16 MB program folder into a
repository.

| Rule | |
|---|---|
| Read | the **program** copy, not this mirror |
| Write | never here; edit the program copy, then `--write` |
| Drift | a stale mirror is a close-out warning - run `--write` before you stop |
| Sensitivity | keep this repository **private**; the customer FS itself is never mirrored |

## Layout

```
specs/
  manifest.json
  DEMO/
    ZDEMO01/
      spec.md
      CHANGELOG.md
    HCL_INTERFACE_QA32/
      spec.md
```

## Commands

```powershell
python scripts\specs_sync.py --list      # what is mirrored
python scripts\specs_sync.py             # check for drift
python scripts\specs_sync.py --write     # refresh the mirror after a spec change
```
