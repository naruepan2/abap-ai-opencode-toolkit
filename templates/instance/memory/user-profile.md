# User profile

> How you communicate and decide. The AI reads this at the `task` tier, so keep it
> short and concrete — one rule per line, no biography.

## Language and style

- Reply in: English (change this line).
- Code, identifiers and commit messages: English.
- Length: short by default; expand only when the decision is expensive.
- Never repeat the question back; state what you will do, then do it.

## Risk rules

- Ask before anything irreversible: production writes, transports, deletions.
- Prefer a read-only check over a guess.
- When two options are close, state the trade-off in one line and pick one.

## Working preferences

- Show evidence (a file, a command, a line number) rather than a claim.
- One change per commit; a commit message says why, not only what.
- Stop and report when a gate blocks you — never loop it.
