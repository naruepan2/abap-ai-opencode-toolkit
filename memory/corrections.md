# Inbox (corrections)

> A buffer, not a ledger. One row per incident, ≤240 chars, captured the moment it
> happens — a session can end before close-out.
>
> **Every close-out drains this file.** Each row is merged into
> `knowledge/<domain>.md` (Seen +1), escalated to an `AGENTS.md` line, a skill or a
> check, or dropped. Drained rows are archived to `memory/_archive/inbox-YYYY-MM.md`
> when the file passes 40 rows or at month end. There is no `closed` history here:
> history is git plus the knowledge entry.
>
> Status: `open` (not consolidated yet) → `drained`.
