# Project memory

One file per project. Keep it short and current.

## Template

```markdown
# <project>

## Resume card
- Status:
- Next step:
- Do not:

## Goal

## Constraints

## Environment

## Business rules

## Code map

## Decisions

## Known unknowns

## Evidence
```

## Rules

- Update the resume card at the end of every session.
- Move durable, cross-project lessons to `../lessons.md`.
- Move repeated patterns to `../skill-candidates.md`.
- No credentials, no customer data.
